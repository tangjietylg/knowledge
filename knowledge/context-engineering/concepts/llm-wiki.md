# LLM-Wiki

## 核心理念

LLM-Wiki 是一个针对垂直领域的知识库结构化框架，核心思想是：

> **把"读"和"查"分离——离线完成理解与结构化，在线只做查询和推理。**

## 对比 RAG

| | RAG | LLM-Wiki |
|---|---|---|
| 核心动作 | 用时现搜 | 提前结构化 |
| 召回内容 | 相关片段 | 完整实体及关联 |
| 信息完整性 | 难以保证 | 天然保证 |
| 适用场景 | 简单问答 | 深度理解、一致性要求高的任务 |

## 实现方式

### 离线阶段（一次性）
1. 通读原始材料（剧本、文档等）
2. 人工设计 Schema（实体类型、关系）
3. LLM 按 Schema 抽取实体
4. 人工审核和质量把控
5. 存入结构化知识库

### 在线阶段（每次查询）
1. 用户提问或 Agent 任务
2. 从结构化知识库查询相关实体
3. 组装上下文，调用 LLM
4. 输出结果

## 核心价值

1. **完整性**：所有相关信息已结构化，不会遗漏
2. **一致性**：实体关系是预先定义好的，不会矛盾
3. **可推理**：知识图谱可以支持复杂推理
4. **与模型解耦**：知识库存好，模型升级直接收益

## 典型案例

游戏剧本知识库：
- 实体类型：人物、地点、技能、物品、组织、势力
- 关系：人物-地点、人物-组织、技能-物品等
- 人工设计 Schema 保证质量，LLM 辅助抽取和维护
